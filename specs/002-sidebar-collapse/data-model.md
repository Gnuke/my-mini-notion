# Data Model: 사이드바 접기/펼치기

**Feature**: `002-sidebar-collapse` | **Date**: 2026-07-16

이 기능은 영속 데이터 모델을 변경하지 않는다. `Post`·`Profile`·localStorage
스키마(`mini-nook-v1`)는 그대로다. 새로 도입되는 것은 화면 상태 값 하나뿐이다.

## 엔티티

### SidebarCollapsed (화면 상태)

| 항목 | 값 |
| --- | --- |
| 타입 | `boolean` |
| 소유자 | 업무 페이지 컴포넌트(`app/(app)/page.tsx`)의 로컬 `useState` |
| 초기값 | `false` (펼침 — FR-008) |
| 영속화 | 하지 않음 (Clarifications 확정 — 새로고침·재방문·마이 페이지 왕복 시 초기값으로 복귀) |
| 파생/저장 관계 | 글 데이터·선택 상태·검색어와 무관 (FR-005). 어떤 저장소에도 기록되지 않음 |

## 상태 전이

```text
        토글 버튼 클릭
펼침 (false) ─────────────▶ 접힘 (true)
   ▲                            │
   └────────────────────────────┘
        토글 버튼 클릭

마운트(첫 진입·새로고침·마이 페이지에서 복귀) → 항상 펼침 (false)
```

- 전이는 토글 버튼 클릭 단 하나뿐이며, 클릭마다 반전된다(연타 시 마지막 클릭
  기준 — US1 시나리오 4).
- 전이 시 부수효과 없음: 글 데이터·선택·검색어·스토어를 건드리지 않는다.

## 상태에 따른 표시 규칙

| 대상 | 펼침 (`false`) | 접힘 (`true`) |
| --- | --- | --- |
| 아이콘 레일 내용(타일·홈·새 글·아바타) | 표시 | 숨김(미렌더) |
| 토글 버튼 | 표시 — "사이드바 접기" | 표시 — "사이드바 펼치기" (같은 위치) |
| 글 목록 패널(PostList) | 표시 | 숨김(`display: none`, **마운트 유지** — 검색어 보존) |
| 편집 영역(에디터/빈 상태) | 나머지 폭 | 스트립(60px) 제외 전체 폭 |

## 검증 규칙

- 타입이 boolean 두 값뿐이므로 유효성 검증 불요. 잘못된 상태가 존재할 수 없다.
- 마이 페이지에는 이 상태가 존재하지 않는다(FR-009 — 컴포넌트 자체가 상태를
  갖지 않고, 프롭 없는 레일을 렌더).
