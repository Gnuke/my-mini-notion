# UI 계약: 사이드바 접기/펼치기

**Feature**: `002-sidebar-collapse` | **Date**: 2026-07-16

사용자에게 노출되는 동작 계약. 구현 파일이 바뀌어도 이 계약은 유지되어야 한다.
스타일 리터럴 값의 근거는 `DESIGN.md` §4.1(IconRail)이며, 구현 시 같은 작업
단위로 DESIGN.md에 아래 내용을 반영한다(헌법 V).

## 1. 토글 버튼

| 항목 | 계약 |
| --- | --- |
| 개수 | 화면에 정확히 1개 (업무 화면 한정 — 마이 페이지에는 없음, FR-009) |
| 위치 | 사이드바(레일/스트립) 최상단 — 접힘/펼침 상태에서 같은 위치 |
| 펼침 상태 라벨 | `title` + `aria-label` = **"사이드바 접기"**, 아이콘 lucide `panel-left-close` 19px |
| 접힘 상태 라벨 | `title` + `aria-label` = **"사이드바 펼치기"**, 아이콘 lucide `panel-left-open` 19px |
| 스타일 | 기존 RailButton과 동일 (34×34, `--radius-md`, default 투명/hover `--surface-hover`, 아이콘 색 `--text-tertiary`) |
| 동작 | 클릭마다 접힘 ↔ 펼침 반전 (FR-002·FR-003). 연타에도 마지막 클릭 기준 상태 (US1-4) |

## 2. 펼침 상태 (기본 — FR-008)

- 왼쪽에서 오른쪽으로: 아이콘 레일(60px: 토글 버튼 → 워크스페이스 타일 → 홈 →
  새 글 → 스페이서 → 아바타) → 글 목록 패널(256px) → 편집 영역(나머지).
- 토글 버튼 외의 기존 레일·글 목록·에디터 동작은 이 기능 이전과 동일해야 한다.

## 3. 접힘 상태

- 왼쪽 가장자리에 **60px 스트립**만 남는다: 기존 레일 컨테이너와 동일한 시각
  (배경 `--surface-sidebar`, 우측 보더 `--border-subtle`, `padding: 12px 0`)에
  내용은 토글 버튼 하나뿐.
- 워크스페이스 타일·홈·새 글·아바타·글 목록·검색·명령 입력은 **보이지 않고
  포커스도 불가능**해야 한다(접근성 트리에서 제거 — FR-006).
- 편집 영역(에디터 또는 빈 상태 화면)이 스트립을 제외한 전체 폭을 차지한다
  (FR-002, SC-004).
- 열려 있는 글의 편집(제목·본문·이모지·커버)과 자동 저장은 평소와 동일하게
  동작한다(FR-006, US2-1).

## 4. 상태 보존 (FR-005)

- 접기/펼치기는 표시만 바꾼다. 다음이 접기 전과 동일하게 유지되어야 한다:
  - 선택된 글(`selectedId`)과 에디터 내용
  - 글 목록 검색 입력값·명령 입력값 (→ PostList는 접힘 중에도 마운트 유지)
  - 글 데이터 전체
- 접힘/펼침 상태 자체는 저장하지 않는다: 새로고침·재방문·마이 페이지 왕복 후엔
  펼침으로 시작한다.

## 5. 전환

- 모션 없음 — 클릭 즉시 상태가 바뀐다(FR-010, SC-002). width transition·
  keyframes 금지.

## 6. 적용 범위

- 업무 화면(`/`)에만 적용. 마이 페이지(`/mypage`)는 항상 일반 레일(토글 버튼
  없음)을 표시한다(FR-009).
- 반응형 분기 없음(기존 앱과 동일 — spec Assumptions).
