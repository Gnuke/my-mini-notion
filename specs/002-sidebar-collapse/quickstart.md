## 수동 검증 시나리오 (`npm run dev` → http://localhost:3000)

| # | 시나리오 | 기대 결과 (계약: [contracts/sidebar-collapse-ui.md](./contracts/sidebar-collapse-ui.md)) |
| --- | --- | --- |
| 1 | 로그인 후 업무 화면 진입 | 사이드바 펼침 기본. 레일 최상단에 "사이드바 접기" 버튼(19px 아이콘) |
| 2 | 토글 버튼 클릭 | 즉시(모션 없음) 60px 스트립만 남고 편집 영역이 넓어짐. 스트립 안 버튼 라벨은 "사이드바 펼치기" |
| 3 | 접힌 상태에서 본문 입력 | 편집·자동 저장 표시("저장됨 ✓") 평소와 동일 |
| 4 | 검색어 "PRD" 입력 → 접기 → 펼치기 | 검색 입력값과 필터된 목록이 그대로 유지 |
| 5 | 접힌 상태 확인 | 홈·새 글·아바타·글 목록이 보이지 않음. Tab 순회에도 등장하지 않음 |
| 6 | 토글 연타(10회) | 짝수 회 후 펼침·홀수 회 후 접힘. 화면 깨짐 없음 (SC-005) |
| 7 | 접기 → 새로고침 | 펼침 상태로 시작 (비영속) |
| 8 | 펼치기 → 아바타 → 마이 페이지 | 마이 페이지엔 레일 항상 표시, 토글 버튼 없음 (FR-009) |
| 9 | 글 미선택(모두 삭제) 후 접기 | 빈 상태 화면이 스트립 제외 전체 폭. 토글 버튼 접근 가능 |
