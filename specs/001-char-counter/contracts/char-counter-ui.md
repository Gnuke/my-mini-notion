# UI Contract: 글자 수 배지

**Feature**: 001-char-counter | **Date**: 2026-07-10

에디터 화면이 사용자에게 보장하는 계약. 테스트(`components/Editor.test.tsx`,
`lib/chars.test.ts`)는 이 계약을 검증한다.

## C1. 가시성

| 조건 | 계약 |
| --- | --- |
| 글이 선택되어 에디터가 열림 | 배지가 에디터 영역 우측 하단에 표시된다 |
| 글 미선택(빈 상태 화면) | 배지가 DOM에 존재하지 않는다 (FR-007) |
| 본문 스크롤 위치 변화 | 배지 위치·가시성 불변 — 스크롤 영역 밖에 고정 (FR-003) |

## C2. 표시 형식

| 입력 (`active.body`) | 표시 텍스트 |
| --- | --- |
| `""` | `0자` (FR-006) |
| `"안녕하세요"` | `5자` |
| `"a b"` (공백 1) | `3자` |
| `"가\n나"` (줄바꿈 1) | `3자` |
| `"😀"` | `1자` |
| `"👨‍👩‍👧"` (조합 이모지) | `1자` (FR-004) |
| `"🇰🇷"` (국기) | `1자` (FR-004) |

형식: `{정수}자` — 접두 라벨·천 단위 구분 없음. 한국어만 사용 (FR-005).

## C3. 갱신 시점

| 이벤트 | 계약 |
| --- | --- |
| 본문 입력·삭제·붙여넣기 | 같은 렌더 사이클에 새 글자 수 반영 (FR-002) |
| 다른 글로 전환 | 새로 열린 글의 본문 기준 값으로 즉시 교체 (FR-008) |
| 제목 입력·수정 | 글자 수 불변 (FR-001 — 제목 제외) |

## C4. 계산 함수 (`lib/chars.ts`)

```
countChars(text: string): number
```

- 사용자 인지 글자(grapheme cluster) 단위로 센다.
- 공백·줄바꿈 각 1자. 조합 이모지·국기 각 1자.
- 순수 함수: 부수효과 없음, 동일 입력 → 동일 출력.

## C5. 비간섭

- 배지는 클릭·드래그·텍스트 선택을 가로채지 않는다 (`pointer-events: none`).
- 열린 팝오버(삭제 확인·이모지·커버)보다 항상 아래에 그려진다.
